# История NERKN

Записи основаны на сообщениях канала [NERKN | kere](https://t.me/nerknn). Даты ниже относятся к публикациям; анонс будущего выпуска не равен готовой сборке.

## 08 августа 2026 — начало проекта

Анонс NERKN и бета-версии с обозначением `Beta 1.10.0`. Главная идея — простой запуск zapret без ручной настройки. Готовый билд и репозиторий GitHub были объявлены как планы.

## 11 августа 2026 — первый установщик

Опубликован `ZapretGUI-Setup.exe` и объявлен выпуск GUI для zapret-discord-youtube. Автор отдельно сообщил о проблеме с пунктом «Открыть после установки» и рекомендовал запуск через ярлык рабочего стола. Это историческая заметка, не описание текущего состояния программы.

## 18 сентября 2026 — версия 1.6.2

- Встроен Telegram-прокси.
- Добавлено переключение тем.
- Появились настройки IPSet и Game Filter.
- Улучшена стабильность.

Опубликован установщик `NERKN-Setup.exe`. Для конфликта со старой установкой ZapretGUI автор описал способ переустановки.

## Следующее обновление — исходники готовы

- Упрощено оформление: готовые наборы, основные цвета, дополнительные параметры в свёрнутых разделах, слоты и импорт/экспорт `.rknth`.
- Исправлены сохранение темы и галочек автозапуска, копирование текущего кода темы и масштаб окна.
- «Лучший поиск» вынесен на главный экран; обновлены справка и ручное управление.
- При занятом порте Telegram-прокси приложение спрашивает, закрыть ли распознанный сторонний прокси.
- Повторные уведомления объединяются со счётчиком.
- Подготовлены исходники и русская документация для GitHub.

Дата и номер следующего релиза будут указаны автором после публикации сборки.
