# Участие в разработке

Для сообщения об ошибке укажите версию Windows и приложения, шаги воспроизведения, ожидаемое и фактическое поведение. Прикладывайте только нужный фрагмент журнала; удалите секрет прокси, личные домены и другие приватные сведения.

Изменения проверяйте командами из [руководства разработчика](docs/Разработка.md). Если меняется интерфейс, проверяйте светлую и тёмную схемы, масштабы 100% и 150%, доступность кнопок и перезапуск приложения с сохранёнными настройками.

В pull request опишите проблему, новое поведение и выполненные проверки. Не добавляйте временные файлы, EXE сборки или личную конфигурацию.
