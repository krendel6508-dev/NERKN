# NERKN

**Zapret и Telegram-прокси в одном понятном приложении для Windows.**

NERKN я делаю для тех, кто хочет открыть приложение, нажать кнопку и пользоваться нужными сервисами, а не разбираться в десятках стратегий и отдельных инструкций. Даже если раньше вы не настраивали обход блокировок, начать можно с автоматического подбора: программа проверит доступные стратегии и покажет, что получилось.

В основе NERKN — два проекта Flowseal: [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy). NERKN объединяет их в одном интерфейсе и добавляет удобное управление, темы, подсказки и сохранение настроек. Исходные проекты остаются самостоятельными: их можно изучать и собирать отдельно.

> NERKN — оболочка для упрощения настройки. Рабочая стратегия зависит от вашей сети и блокировки; приложение не обещает, что один способ подойдёт каждому.

## Что умеет NERKN

- **Обход в один клик.** Нажмите «Найти и включить обход» — приложение попробует стратегии и установит найденную как службу.
- **«Лучший поиск».** Если обычного подбора недостаточно, можно проверить все стратегии и выбрать лучший результат.
- **Ручной выбор.** Для опытных пользователей есть прямой запуск выбранной стратегии, Game Filter, IPSet и свои домены.
- **Telegram-прокси.** Встроенный прокси запускается прямо из приложения; ссылку подключения можно открыть в Telegram.
- **Оформление под себя.** Готовые темы и наборы цветов, редактор своей темы, пять слотов, импорт и экспорт `.rknth`, масштаб окна.
- **Работа в трее и автозапуск.** Настройки сохраняются между запусками, а состояние и ошибки показываются в интерфейсе.

## Как начать

Если у вас готовый установщик NERKN, установите приложение и откройте его. На главном экране нажмите **«Найти и включить обход»**. Ход проверки появится в журнале. Для Telegram перейдите во вкладку **«Telegram прокси»**, включите его и нажмите **«Применить в телеграм»**.

При занятом порте NERKN покажет уведомление с выбором: закрыть распознанный сторонний Telegram-прокси или отменить запуск. Посторонний процесс без подтверждения не завершается.

Для постоянной работы обхода используется служба Windows. Закрытие окна сворачивает NERKN в трей; полностью выйти можно через меню иконки в трее.

## Запуск из исходников и сборка

Проект рассчитан на **Windows**. Для запуска из исходников нужен **Python 3.12**, а для окна — **Microsoft Edge WebView2 Runtime**. Приложение запрашивает права администратора для управления службой и WinDivert.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Для сборки `NERKN.exe` и установщика используйте `installer_kit\build.bat`; установщик собирается при наличии **Inno Setup 6**. Подробности — в [инструкции по сборке](docs/Сборка.md). Для работы программы папки `bin`, `lists`, `utils`, `zapretes` и `proxy` должны оставаться рядом с `main.py` или собранным EXE.
