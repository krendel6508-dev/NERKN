# Сборка для Windows

NERKN объединяет zapret и Telegram-прокси в одном окне, чтобы пользователь мог быстро включить нужную функцию без ручной настройки исходных проектов. Эта инструкция собирает оболочку NERKN. [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) можно изучать и собирать отдельно по их документации.

## Подготовка

1. Установите Python 3.12 x64 с Tkinter.
2. Для установщика нужен Inno Setup 6. Без него будет собран EXE с рабочими файлами в `installer_kit\dist`.
3. Откройте PowerShell в корне проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
```

## Сборка одной командой

```powershell
.\installer_kit\build.bat
```

Скрипт предпочитает `.venv\Scripts\python.exe`, затем использует Python из PATH. Зависимости берутся из `requirements-build.txt`. При отсутствии иконки запускается `make_icon.py`.

Результаты:

- `installer_kit\dist\NERKN.exe` — приложение.
- Папки рядом с ним — обязательные рабочие данные, в том числе `proxy`.
- `installer_kit\Output\NERKN-Setup.exe` — установщик, если найден Inno Setup.

Один `NERKN.exe` без соседних папок не является полным переносимым дистрибутивом. Перед выпуском проверяйте состав папки `dist`.

Изменение исходников не обновляет ранее собранный EXE: после правок соберите новый комплект. Авторство и условия встроенных компонентов описаны в [уведомлении](../THIRD_PARTY_NOTICES.md).

## Проверка выпуска

Проверьте на Windows запуск приложения, запрос прав, WebView2, подбор стратегии, ручной запуск, Telegram, копирование темы, импорт/экспорт и восстановление настроек после выхода. Автоматические проверки не заменяют проверку драйвера и сетевого подключения.

Кэш `installer_kit\build` можно удалить при остановленном сборщике. `dist` и `Output` не добавляются в Git; готовые сборки можно приложить к GitHub Releases.

## Пользовательские файлы

Рабочий компьютер может содержать личные домены в `lists\*-user.txt`. Они исключены из Git, но обычная локальная сборка копирует папку `lists` как есть. Для публичного выпуска используйте чистую копию репозитория, а не каталог с личными настройками.
